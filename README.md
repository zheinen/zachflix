# ZachFlix

A personal media library and lending application.

ZachFlix allows users to browse a collection of physical media, search and filter the collection, and check out available items.

## Project Goals

- Catalog physical media
- Support movies, books, music, video games, board games, and card games
- Track individual physical copies
- Track availability
- Allow registered users to check out media
- Track loan history
- Provide search, filtering, and sorting
